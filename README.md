# circles-game
Cloned the essential functionality of a popular mobile game by prompting ai.

## How I used AI

I used ChatGPT (via duck.ai) to make a clone of the essential functionality of a popular mobile game.

I used a bottom-up approach -- meaning that I started by telling chatgpt to draw a circle, then draw a grid of circles. After getting the circles drawn, connecting the circles with lines was more difficult as it took a few attempts to get ChatGPT to understand what I wanted. The end result worked, however. After that, it was onto making circles disappear and new circles fall into place.

## Usage

**Usage**: Download game.html and run locally in your browser. Security warnings are safe to click through as the code is 100% client side.
